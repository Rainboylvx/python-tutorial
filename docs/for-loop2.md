# 嵌套 `for` 循环

## 学习目标

学完这一课，你应该能够：

1. 理解什么是嵌套循环。
2. 使用外层循环控制行，内层循环控制列。
3. 写出九九乘法表。
4. 用嵌套循环打印简单图形。

## 什么是嵌套循环

嵌套循环就是“循环里面还有循环”。

外层循环每执行一次，内层循环都会完整执行一遍。

例如：

```python
for i in range(1, 4):
    for j in range(1, 4):
        print(i, j)
```

输出：

```text
1 1
1 2
1 3
2 1
2 2
2 3
3 1
3 2
3 3
```

可以这样理解：

- 外层循环控制 `i`。
- 内层循环控制 `j`。
- 每一个 `i`，都会配上所有的 `j`。

## 九九乘法表

九九乘法表的输出大概是这样：

```text
1x1=1
1x2=2 2x2=4
1x3=3 2x3=6 3x3=9
...
1x9=9 2x9=18 ... 9x9=81
```

观察规律：

1. 第 `i` 行有 `i` 个公式。
2. 每行的第二个数字是 `i`。
3. 每行的第一个数字从 `1` 增加到 `i`。
4. 每个公式的结果是 `i * j`。

## 参考代码

```python
for i in range(1, 10):
    for j in range(1, i + 1):
        print(f"{j}x{i}={i*j}", end=" ")
    print()
```

## 代码解析

### 外层循环控制行

```python
for i in range(1, 10):
```

`i` 会依次变成 `1` 到 `9`。

当 `i = 1` 时，打印第 1 行。

当 `i = 2` 时，打印第 2 行。

依次类推。

### 内层循环控制每行内容

```python
for j in range(1, i + 1):
```

`j` 从 `1` 变化到 `i`。

所以第 `i` 行正好打印 `i` 个公式。

### 不换行输出

```python
print(f"{j}x{i}={i*j}", end=" ")
```

默认情况下，`print()` 输出后会换行。

这里使用 `end=" "`，表示输出后用空格结尾，不马上换行。

### 行末换行

```python
print()
```

当内层循环结束后，执行一次空的 `print()`，让下一行从新的一行开始。

## 练习题

### 1. 打印星号正方形

使用嵌套循环，打印一个 `5 x 5` 的星号正方形。

输出效果：

```text
*****
*****
*****
*****
*****
```

参考代码：

```python
for i in range(5):
    for j in range(5):
        print("*", end="")
    print()
```

### 2. 打印直角三角形

打印一个高度为 `5` 的直角三角形。

输出效果：

```text
*
**
***
****
*****
```

参考代码：

```python
for i in range(1, 6):
    for j in range(i):
        print("*", end="")
    print()
```

### 3. 只打印乘积为偶数的公式

修改九九乘法表代码，只打印乘积为偶数的公式。

提示：可以在内层循环中使用 `if`。

```python
for i in range(1, 10):
    for j in range(1, i + 1):
        if i * j % 2 == 0:
            print(f"{j}x{i}={i*j}", end=" ")
    print()
```

## 本课小结

- 嵌套循环就是循环里面还有循环。
- 外层循环常用来控制行。
- 内层循环常用来控制列。
- 九九乘法表是理解嵌套循环的经典例子。
